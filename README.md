# TinyLink URL Shortener

TinyLink is a simple URL shortening web application built with Node.js and Express. It allows users to shorten long URLs and manage them easily. Shortened URLs redirect users to the original long URLs.

## Features

- Shorten long URLs instantly
- Redirect short URLs to original URLs
- Manage links via a JSON file (`links.json`)
- Clean and minimal frontend interface
- Easy to set up and run locally
